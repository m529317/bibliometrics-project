# AI工具使用说明

## 一、使用的AI工具

### 1. GitHub Copilot
- **工具类型**: AI代码助手
- **版本**: GitHub Copilot Enterprise
- **获取方式**: 通过GitHub账号订阅

### 2. ChatGPT (GPT-4)
- **工具类型**: 大型语言模型
- **版本**: GPT-4 Turbo
- **获取方式**: OpenAI API / ChatGPT Plus订阅

## 三、人工核验方式

### 1. 代码正确性核验

#### 1.1 数据清洗模块
- **核验方法**: 
  - 运行脚本后检查输出文件是否存在
  - 随机抽取10%文献人工核对清洗前后数据
  - 验证去重逻辑：检查重复文献是否被正确剔除
- **核验标准**:
  - 清洗后数据关键字段（标题、作者、年份）无缺失
  - 重复文献检出率≥95%
  - 格式统一，无特殊字符残留

#### 1.2 可视化模块
- **核验方法**:
  - 运行脚本生成图表后人工检查
  - 验证图表元素完整性（标题、坐标轴、图例）
  - 检查中文显示是否正常
- **核验标准**:
  - 图表内容与数据一致
  - 中文无方框乱码
  - 图表布局合理美观

#### 1.3 分析模块
- **核验方法**:
  - 手动计算部分数据验证算法正确性
  - 检查输出结果是否符合预期
  - 对比同领域类似研究结果
- **核验标准**:
  - 统计结果准确无误
  - 分析结论合理可靠

### 2. 文档内容核验

#### 2.1 README文档
- **核验方法**:
  - 对照实际项目结构检查目录说明
  - 逐条验证运行命令是否可执行
  - 确认人员分工与实际贡献一致
- **核验标准**:
  - 目录结构描述准确
  - 运行命令可正确执行
  - 信息完整无遗漏

#### 2.2 技术文档
- **核验方法**:
  - 对照代码检查函数说明准确性
  - 验证模块依赖关系描述
  - 检查运行指南可操作性
- **核验标准**:
  - 文档与代码保持同步
  - 技术描述准确无误
  - 操作指南清晰可执行

### 3. 输出结果核验

#### 3.1 图表输出
- **核验方法**:
  - 检查图表文件格式（PNG）
  - 验证分辨率（≥300dpi）
  - 确认文件完整性
- **核验标准**:
  - 文件格式正确
  - 图像清晰无模糊
  - 文件无损坏

#### 3.2 数据输出
- **核验方法**:
  - 检查RIS文件格式合规性
  - 验证CSV/TXT文件编码（UTF-8）
  - 随机抽样检查数据准确性
- **核验标准**:
  - 文件可被CiteSpace/VOSviewer正常导入
  - 数据编码正确无乱码
  - 数据记录完整
